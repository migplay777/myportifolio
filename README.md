# Portfólio de Miguel Roberto da Silva

Site estático com temática de cinema, apresentando Bingeo, FIGO, MissiON, experiências, formação e contato.

## Configuração no Render

- Tipo: Static Site
- Branch: main
- Build Command: true
- Publish Directory: dist
- Atualizações automáticas: ativadas, quando o repositório estiver conectado ao Render
- Sem banco de dados, chaves ou variáveis obrigatórias

Publique este conteúdo em um repositório GitHub próprio e conecte esse repositório ao Render. Mantenha a estrutura `dist/` como está. As fontes e imagens são locais, sem dependências externas em tempo de execução.

Os metadados de endereço da hospedagem anterior foram retirados desta cópia. Após o Render atribuir a URL definitiva, ela pode ser adicionada como canonical e usada na imagem Open Graph.
